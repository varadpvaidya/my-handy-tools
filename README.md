# 🛠️ My Handy Tools

Hey! Welcome to **My Handy Tools** 👋

This is my little project where I'm building simple tools that actually come in handy. No unnecessary stuff, no confusing UI, just tools that get the job done.

## 🚀 What's inside?

- **Pressure Vessel Calculator** — Calculates shell and dish thickness, component weights, and total vessel weight.

More tools might get added as I build them!

## 💻 Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide Icons

## 🏃 Running it locally

Wanna run it on your own computer? Easy.

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.

To make a production build:

```bash
npm run build
```

## 📌 A few things

- Keeping things simple is the whole point.
- Calculations run locally in your browser.
- The calculator is still a work in progress, so don't treat its results as certified engineering design.
